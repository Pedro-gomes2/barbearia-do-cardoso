# 💈 BarbShop — Sistema de Agendamento para Barbearias

Sistema moderno de agendamento online para barbearias, desenvolvido com foco em performance, experiência do usuário e gestão inteligente de horários.

## 🚀 Demonstração

🔗 Projeto online: [https://agendamento-barbshop.vercel.app/](https://agendamento-barbshop.vercel.app/)

---

# ✨ Funcionalidades

## 👤 Área do Cliente

* Agendamento online em poucos cliques
* Escolha de barbeiro
* Seleção de serviços
* Escolha de data e horário disponíveis
* Interface responsiva para mobile e desktop
* Histórico de agendamentos
* Cancelamento de agendamentos
* Confirmação de horário

---

## 💼 Área Administrativa

* Dashboard administrativo
* Controle completo de agendamentos
* Cadastro de barbeiros
* Cadastro de serviços
* Controle de horários disponíveis
* Bloqueio de agenda
* Gestão de clientes
* Relatórios básicos
* Controle de disponibilidade por profissional

# ⚙️ Instalação

## 1️⃣ Clone o repositório

```bash
git clone https://github.com/seu-usuario/agendamento-barbshop.git
```

---

## 2️⃣ Acesse a pasta

```bash
cd agendamento-barbshop
```

---

## 3️⃣ Instale as dependências

```bash
npm install
```

ou

```bash
yarn install
```

---

## 4️⃣ Configure as variáveis de ambiente

Crie um arquivo:

```env
.env
```

Exemplo:

```env
DATABASE_URL=
NEXT_PUBLIC_API_URL=
JWT_SECRET=
```

---

## 5️⃣ Execute o projeto

```bash
npm run dev
```
